# Thailand Explorer

เว็บไซต์แนะนำสถานที่ท่องเที่ยวในประเทศไทย สำหรับ 42 Bangkok Discovery Piscine Rush พัฒนาด้วย HTML, CSS และ JavaScript แบบหน้าเดียว ไม่ต้องติดตั้งแพ็กเกจหรือ build ก่อนใช้งาน

## ฟีเจอร์

- แนะนำสถานที่ 9 แห่ง แบ่งเป็นทะเล ภูเขา และวัฒนธรรม หมวดละ 3 แห่ง
- กรองตามหมวด และบันทึกรายการโปรดใน `localStorage` ของเบราว์เซอร์
- เปิดรายละเอียด ช่วงเวลาที่เหมาะสม การเดินทาง เคล็ดลับ และลิงก์ Google Maps
- สุ่มจุดหมายจากสถานที่ทั้งหมด แม้กำลังเลือกหมวดอยู่ และอาจสุ่มได้สถานที่เดิมซ้ำ
- รองรับมือถือ แท็บเล็ต และเดสก์ท็อป พร้อมลดการเคลื่อนไหวตามการตั้งค่าของผู้ใช้
- หน้าแรกเป็นภาพสมจริงแบบ 2.5D Parallax: ฉากไกล ข้อความ และฉากหน้าเลื่อนต่างความเร็วโดยไม่ซูม
- นกเงา 4 ตัวบินวนอัตโนมัติ มีจังหวะกระพือปีกต่างกัน โดยไม่มีปุ่มควบคุม
- รีเฟรชหน้าเว็บแล้วกลับด้านบน และล้างตำแหน่ง section จาก URL

## วิธีเปิดเว็บ

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง หรือหากติดตั้ง Python ให้เปิด terminal ที่โฟลเดอร์โปรเจกต์แล้วรัน:

```sh
python -m http.server 8000
```

จากนั้นเปิด [http://localhost:8000](http://localhost:8000) และกด `Ctrl+C` ใน terminal เมื่อต้องการหยุดเซิร์ฟเวอร์ หากเครื่องใช้คำสั่ง `python3` ให้ใช้แทน `python`

แนะนำให้เปิดผ่านเซิร์ฟเวอร์ขณะพัฒนา เพื่อให้ origin ของ `localStorage` คงที่ เว็บไม่มีขั้นตอน build และไม่ต้องใช้ API key แต่การโหลดฟอนต์ Google Fonts ต้องเชื่อมต่ออินเทอร์เน็ต

## โครงสร้าง

- `index.html` — โครงสร้างหน้าเว็บและ sections ทั้งหมด
- `assets/css/style.css` — layout, สีโทนภูเขายามเช้า, responsive และชั้นภูเขาหน้าแรก
- `assets/js/data.js` — ข้อมูลสถานที่ 9 แห่ง
- `assets/js/main.js` — การแสดงผล ตัวกรอง รายการโปรด รายละเอียด และการสุ่ม
- `assets/images/parallax/realistic-v2/` — ภาพหน้าแรก WebP 4 ชั้น พร้อม prompt; ท้องฟ้าทึบ ส่วนฉากอื่นพื้นใส
- `assets/images/generated/` — ภาพ AI ของหมวด 3 ภาพ และสถานที่ 9 ภาพ พร้อม prompt ใน `prompts.json`
- `assets/photos/` — พื้นที่สำหรับภาพถ่ายสถานที่
- `.github/pull_request_template.md` — เช็กลิสต์ก่อนรวมงาน
- `auteur.example` — ตัวอย่างไฟล์รายชื่อผู้จัดทำ

## ลำดับอ่านโค้ด

1. `index.html` กำหนดพื้นที่และ id ที่ JavaScript ใช้
2. `assets/js/data.js` เก็บ array ของ object แต่ละ object คือสถานที่หนึ่งแห่ง
3. `assets/js/main.js` เรียก `renderDestinations('all')` แล้วสร้างการ์ดผ่าน `createCard`
4. กด Filter จะคัด array ด้วย `filter` แล้ววาดใหม่; กด Random จะสุ่ม index
5. `assets/css/style.css` ใช้ Grid สำหรับการ์ด และ media query เปลี่ยน 3 → 2 → 1 คอลัมน์
6. Parallax มีเฉพาะหน้าแรก: `heroLayers` ใน `main.js` ส่วน 8 กำหนดความเร็วของภาพและข้อความด้วย `depth` ส่วน CSS กำหนดลำดับซ้อนทับด้วย `z-index` โดยไม่ซูมภาพ นกบินวนด้วย CSS และพักเมื่อหน้าแรกพ้นจอหรือแท็บถูกซ่อน การเคลื่อนไหวตกแต่งปิดเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว

รายละเอียดข้อมูลใช้ textContent เพื่อลดความเสี่ยงจากการแทรก HTML และไม่ต้องใช้ framework

## การปรับพารัลแลกซ์และนกบิน

- เปลี่ยนภาพหน้าแรกที่ `assets/images/parallax/realistic-v2/` โดยรักษาขนาดและตำแหน่งของแต่ละเลเยอร์ให้ตรงกัน
- ปรับความเร็วใน `heroLayers` ของ `assets/js/main.js`: `depth` ใกล้ 1 ทำให้ฉากดูอยู่ไกล ส่วน 0 เลื่อนตามเอกสาร ค่าที่ใช้งานจริงอยู่ในรายการนี้ ไม่ใช่ `data-depth` ที่ยังคงอยู่ใน HTML
- ลำดับซ้อนใน CSS คือ ท้องฟ้า → เขาไกลและนก → ข้อความ → เขากับเจดีย์ → ป่าด้านหน้า
- ปรับเส้นทางและระยะเวลาบินที่ `@keyframes birds-pass` และ `.bird-flock` ใน CSS ปัจจุบันวนรอบละ 32 วินาที รวมช่วงเว้นระหว่างฝูง
- ปรับการกระพือปีกที่ `@keyframes bird-wings`; นกเป็น SVG ใน HTML ไม่ต้องโหลดไฟล์ภาพเพิ่ม
- นกพักอัตโนมัติเมื่อหน้าแรกพ้นจอหรือแท็บถูกซ่อน และบินต่อเมื่อกลับมา ผู้ใช้ที่ตั้งค่า Reduce Motion จะไม่เห็นนกและพารัลแลกซ์จะหยุดเคลื่อน

## การแก้ไขข้อมูลและรูปภาพ

แก้ข้อมูลใน `assets/js/data.js` โดยแต่ละสถานที่ต้องมี `id` ไม่ซ้ำ และใช้ `category` เป็น `beach`, `mountain` หรือ `culture`

การ์ดเลือกภาพจาก `photo` ก่อน หากไม่มีจะใช้ `image` หากโหลดไม่ได้จะแสดงภาพประกอบหมวด `assets/images/generated/category-<หมวด>.jpg` แทน ใช้ร่วมกันทั้งรายการสถานที่ หน้ารายละเอียด และผลการสุ่ม

หากเพิ่มภาพถ่าย ให้เก็บใน `assets/photos/` แล้วกำหนด `photo` เช่น `assets/photos/railay.jpg` พร้อมตรวจสิทธิ์และระบุแหล่งที่มาของภาพ

ภาพหน้าแรกสร้างด้วย AI และแยกเป็นเลเยอร์จากภาพอ้างอิงเดียวกัน โดยเก็บ prompt ใน `assets/images/parallax/realistic-v2/prompts.json` ภาพการ์ดและหมวดหมู่เป็น JPEG ใน `assets/images/generated/` พร้อม prompt ในโฟลเดอร์เดียวกัน ภาพ AI เป็นภาพประกอบ อาจแตกต่างจากสถานที่จริง ฟอนต์เรียกจาก Google Fonts

ภาพสำรองเก่า PNG ต้นฉบับซ้ำ ภาพ preview และภาพทดสอบที่ไม่ได้ใช้งานถูกนำออกแล้ว เหลือภาพ WebP สำหรับหน้าแรกและ JPEG สำหรับหมวดหมู่และสถานที่ พร้อมไฟล์ prompt ของภาพที่ใช้งาน

## ไฟล์ที่ไม่ส่งขึ้น GitHub

`.gitignore` ยกเว้นบริบทเครื่องมือออกแบบ (`PRODUCT.md`, `.impeccable/`, `.claude/`), การตั้งค่า editor, ไฟล์ชั่วคราวและ log, `.env`, `node_modules/`, PNG ที่โฟลเดอร์หลัก รวมถึง PNG ต้นฉบับและ preview ของพารัลแลกซ์ชุดปัจจุบัน

ไฟล์ WebP, JPEG ที่เว็บใช้งาน และ `prompts.json` ยังคงอยู่ใน Git ผู้ที่ clone โปรเจกต์เปิดเว็บได้โดยไม่ต้องมี PNG ต้นฉบับ กฎ ignore ของไฟล์ต้นฉบับและบริบทเครื่องมือยังเก็บไว้เพื่อป้องกันไฟล์เหล่านี้ถูกเพิ่มกลับโดยไม่ตั้งใจ อย่าใส่รหัสผ่านหรือ token ลงใน HTML, JavaScript หรือไฟล์ภาพและ prompt

## การตรวจสอบเบื้องต้น

หากติดตั้ง Node.js ให้ตรวจ syntax ด้วย:

```sh
node --check assets/js/data.js
node --check assets/js/main.js
```

เปิดเว็บแล้วตรวจตัวกรอง การเพิ่มและลบรายการโปรด การเปิดและปิดรายละเอียด การสุ่มสถานที่ และการแสดงผลบนหน้าจอขนาดต่าง ๆ

- ทดสอบที่หน้าจอมือถือและเดสก์ท็อป ว่าข้อความและปุ่มไม่ล้นจอ
- เลื่อนหน้าแรกเพื่อดูระยะของแต่ละเลเยอร์ โดยภาพไม่ซูม
- ตรวจว่านกบินวน และพักเมื่อสลับแท็บหรือเลื่อนพ้นหน้าแรก
- ทดสอบการตั้งค่า Reduce Motion และการใช้คีย์บอร์ดกับเมนูและ dialog
- เลื่อนลงแล้วกดรีเฟรช ต้องกลับบนสุดของหน้าเว็บ

## การจัดเก็บข้อมูล

ไม่มี backend หรือฐานข้อมูล ข้อมูลสถานที่เก็บในไฟล์ JavaScript รายการโปรดเก็บเฉพาะเบราว์เซอร์และ origin ที่ใช้งาน ไม่ซิงก์ข้ามอุปกรณ์ หากบันทึกไม่ได้จะเก็บในหน่วยความจำระหว่างเปิดหน้าเว็บ
