# Thailand Explorer

ออกไปค้นพบประเทศไทยในแบบของคุณ

เว็บไซต์แนะนำสถานที่ท่องเที่ยวในประเทศไทย สำหรับ **42 Bangkok Discovery Piscine Rush** รวบรวมจุดหมายทั้งทะเล ภูเขา และวัฒนธรรม ให้เลือกสำรวจ บันทึกสถานที่ที่ชอบ หรือสุ่มไอเดียสำหรับทริปถัดไป

พัฒนาด้วย HTML, CSS และ JavaScript แบบหน้าเดียว ไม่มี framework, backend หรือขั้นตอน build

## ฟีเจอร์

- สำรวจสถานที่ท่องเที่ยว 9 แห่ง แบ่งเป็นทะเล ภูเขา และวัฒนธรรม หมวดละ 3 แห่ง
- กรองตามหมวดและรายการที่ชอบ
- บันทึกรายการโปรดในเบราว์เซอร์ด้วย `localStorage`
- เปิดรายละเอียดจังหวัด ช่วงเวลาที่เหมาะสม การเดินทาง และเคล็ดลับ พร้อมลิงก์ Google Maps
- สุ่มจุดหมายจากสถานที่ทั้งหมด โดยไม่ขึ้นกับหมวดที่กำลังเลือก
- หน้าแรกมีภาพภูเขาซ้อนชั้นแบบพารัลแลกซ์และนกบินประกอบบรรยากาศ
- รองรับมือถือ แท็บเล็ต และเดสก์ท็อป รวมถึงการตั้งค่าลดการเคลื่อนไหว

## เริ่มต้นใช้งาน

ดาวน์โหลดโปรเจกต์ หรือ clone ผ่าน Git:

```sh
git clone https://github.com/Jakkapon-Wapakpet/rush-project.git
cd rush-project
```

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง หรือเปิดผ่าน local server หากติดตั้ง Python:

```sh
python -m http.server 8000
```

จากนั้นเข้า [http://localhost:8000](http://localhost:8000) และกด `Ctrl+C` ใน terminal เพื่อหยุดเซิร์ฟเวอร์ หากเครื่องใช้คำสั่ง `python3` ให้ใช้แทน `python`

ไม่ต้องติดตั้งแพ็กเกจหรือใช้ API key แนะนำให้ใช้ local server ระหว่างพัฒนา และเปิดใช้งาน JavaScript ฟอนต์ Kanit และ Prompt โหลดจาก Google Fonts จึงต้องใช้อินเทอร์เน็ตในการโหลดฟอนต์เหล่านี้

## วิธีใช้งาน

1. กด **เริ่มสำรวจ** แล้วเลือกหมวดที่สนใจ หรือดูสถานที่ทั้งหมด
2. กด **ดูรายละเอียด** บนการ์ด เพื่ออ่านข้อมูลและเปิด Google Maps
3. กดรูปหัวใจเพื่อบันทึกสถานที่ แล้วเลือก **ที่ชอบ** เพื่อดูภายหลัง
4. หากยังเลือกไม่ได้ กด **สุ่มสถานที่ท่องเที่ยว** เพื่อรับจุดหมายหนึ่งแห่ง การสุ่มแต่ละครั้งอาจได้สถานที่เดิมซ้ำ

เมื่อรีเฟรช เว็บจะกลับด้านบนของหน้าและล้างตำแหน่ง section จาก URL

## โครงสร้างโปรเจกต์

```text
index.html
auteur
README.md
.gitignore
.github/
└── pull_request_template.md
assets/
├── css/
│   └── style.css
├── js/
│   ├── data.js
│   └── main.js

    └── parallax/
        └── realistic-v2/   # ภาพหน้าแรก WebP 4 ชั้น พร้อม prompts.json
```

- `index.html` — โครงสร้างหน้าเว็บ เมนู หมวดท่องเที่ยว และหน้าต่างรายละเอียด
- `auteur` — ไฟล์ระบุ 42 login ของสมาชิกผู้จัดทำตามข้อกำหนดการส่งงาน Discovery Piscine Rush
- `assets/css/style.css` — สี ฟอนต์ การจัดวาง responsive และเอฟเฟกต์ภาพ
- `assets/js/data.js` — ข้อมูลสถานที่ท่องเที่ยวทั้งหมด
- `assets/js/main.js` — สร้างการ์ด กรองข้อมูล จัดการรายการโปรด เปิดรายละเอียด และสุ่มสถานที่
- `assets/images/` — ภาพที่เว็บใช้งานและ prompt ของภาพที่สร้างด้วย AI

## การแก้ไขข้อมูลสถานที่

แก้ข้อมูลใน `assets/js/data.js` โดยแต่ละสถานที่มีข้อมูลหลักดังนี้:

| ชื่อข้อมูล | หน้าที่ |
|---|---|
| `id` | รหัสสถานที่ ต้องไม่ซ้ำกัน ใช้อ้างอิงรายการโปรด |
| `name`, `province` | ชื่อสถานที่และจังหวัด |
| `category` | หมวด `beach`, `mountain` หรือ `culture` |
| `description` | คำอธิบายสถานที่ |
| `season`, `trip`, `tip` | ช่วงเวลา การเดินทาง และเคล็ดลับ |
| `tags` | รายการคำสำคัญที่แสดงบนการ์ด |
| `image`, `imageAlt` | ตำแหน่งภาพประกอบและข้อความอธิบายภาพ |
| `photo` | ตำแหน่งภาพถ่าย หากไม่มีให้ใช้ `null` |

ระบบเลือกภาพจาก `photo` ก่อน หากไม่มีจะใช้ `image` และถ้าโหลดภาพไม่สำเร็จจะลองใช้ภาพสำรองประจำหมวด ใช้กติกาเดียวกันทั้งการ์ดรายการ หน้ารายละเอียด และผลการสุ่ม

หากเพิ่มภาพใหม่ ให้เก็บไฟล์ไว้ในโปรเจกต์ กำหนดตำแหน่งภาพให้ตรง และตรวจสิทธิ์การใช้งานก่อนเผยแพร่

## ข้อมูลและภาพประกอบ

เว็บไซต์ไม่มีระบบบัญชีหรือฐานข้อมูล ข้อมูลสถานที่เก็บในไฟล์ JavaScript ส่วนรายการโปรดเก็บเฉพาะเบราว์เซอร์และ origin ที่ใช้งาน ไม่ซิงก์ข้ามอุปกรณ์ หากเบราว์เซอร์ไม่อนุญาตให้บันทึก จะเก็บรายการโปรดไว้ชั่วคราวระหว่างเปิดหน้าเว็บ

ภาพท่องเที่ยวสร้างด้วย AI เพื่อประกอบเนื้อหา อาจแตกต่างจากสถานที่จริง โดยเก็บ prompt ไว้ในโฟลเดอร์ภาพแต่ละชุด ข้อมูลฤดูกาล การเดินทาง และเคล็ดลับเป็นข้อมูลทั่วไป ควรตรวจสอบกับแหล่งทางการก่อนเดินทาง

`.gitignore` ยกเว้นไฟล์ตั้งค่าเฉพาะเครื่อง ไฟล์ชั่วคราว ข้อมูลลับใน `.env` และไฟล์ต้นฉบับที่ไม่ได้ใช้แสดงบนเว็บ ส่วนภาพที่จำเป็นต่อการใช้งานยังเก็บใน Git ครบ

## ตรวจสอบก่อนส่งงาน

ตรวจสอบไฟล์รายชื่อผู้จัดทำ (auteur) ตามข้อกำหนดของ 42:

```sh
cat -e auteur
```

*(ผลลัพธ์ต้องแสดง `jwapakpe$` และ `jpremsir$` โดยมี `$` ท้ายชื่อทั้งสองบรรทัด)*

หากติดตั้ง Node.js สามารถตรวจไวยากรณ์ JavaScript ได้ด้วย:

```sh
node --check assets/js/data.js
node --check assets/js/main.js
```

- ตรวจสอบว่าไฟล์และทรัพยากรทั้งหมด (CSS, JS, รูปภาพ) อยู่ภายในโฟลเดอร์โปรเจกต์ ไม่อ้างอิงไฟล์ภายนอกเครื่อง
- เปิดเว็บและตรวจว่าภาพโหลดครบ ไม่มีข้อความหรือปุ่มล้นจอ
- ตรวจตัวกรองทั้งหมดและแต่ละหมวด รวมถึงกรณีรายการโปรดยังว่าง
- ลองเพิ่มและลบรายการโปรด แล้วรีเฟรชเพื่อทดสอบการบันทึก
- เปิดและปิดรายละเอียด พร้อมทดสอบลิงก์ Google Maps และการสุ่ม
- ทดสอบมือถือและเดสก์ท็อป การใช้คีย์บอร์ด และการตั้งค่า Reduce Motion
- ตรวจข้อมูลสถานที่ แหล่งที่มาของภาพ และข้อกำหนดงานต้นฉบับ
