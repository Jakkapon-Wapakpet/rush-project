# รูปภาพ
ภาพประกอบทั้งหมด (hero.svg, beach.svg, mountain.svg, culture.svg) เขียนเป็น SVG ในโปรเจกต์นี้ ไม่ใช่รูปถ่ายสถานที่
Hero และ Scenic ใช้ hero.svg

## วิธีใส่ภาพถ่ายจริง
1. เก็บไฟล์ใน assets/photos/<id>.jpg (id ตาม js/data.js เช่น railay.jpg)
2. แก้ฟิลด์ `photo` ของสถานที่นั้นใน data.js (ถ้าโหลดไม่ได้จะถอยกลับไปใช้ภาพประกอบเอง)
3. บันทึกตารางด้านล่างทุกครั้ง

| สถานที่ | URL ต้นฉบับ | ผู้สร้าง | License | Attribution |
|---|---|---|---|---|

ห้ามใช้ภาพประกอบแล้วระบุว่าเป็นภาพถ่ายสถานที่จริง
